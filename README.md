# 보증금 반환 합의서

회사 전세권이 설정된 전세보증금을, 세입자가 회사 대출을 먼저 갚고 전세권을 말소한 뒤 세입자 본인에게 반환하는 방법에 관한 합의서입니다. 공개용 사본이라 이름과 주소는 ○○○로 가렸습니다.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 화면 |
| `guide.html` | 합의서를 그림으로 쉽게 풀어 쓴 설명 |
| `agreement.html` | 합의서 원본 (인쇄 가능) |
| `agreement.docx` | 출력용 Word 파일 |

## 수정 요청

모든 페이지 오른쪽 아래의 **수정 요청** 버튼이나 조항 옆 버튼을 누르면 의견을 적어 문자·카톡으로 공유하거나, GitHub 이슈로 남길 수 있습니다.

## 내용 고치는 방법

`build/agreement.json` 하나만 고친 뒤 아래를 실행하면 HTML과 Word가 같은 내용으로 다시 만들어집니다.

```bash
python3 build/make_html.py
node build/make_docx.js
```
